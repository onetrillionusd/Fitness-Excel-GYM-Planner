# Fitness Excel GYM Planner

This repository contains a ready-to-run Excel workbook generator for a comprehensive gym and fitness follow-up planner.

## Included workbook tabs
- Dashboard
- Weekly Plan
- Workout Log
- Exercise Library
- Progress Tracker
- Body Measurements
- Goal Planner
- Notes / Coaching
- Settings

## How to generate the workbook

1. Install Python 3.9+
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the generator:
   ```bash
   python workbook_generator.py
   ```
4. The workbook will be created at:
   ```bash
   Fitness_GYM_Planner.xlsx
   ```

## Features
- Weekly workout schedule
- Exercise tracking and sets/reps/weight logging
- Goal tracking by muscle group and fitness target
- Progress charts and KPI dashboard
- Measurements history
- Trainer/coach notes
- Auto-formatted planner layout suitable for Excel and Google Sheets

## Notes
This workbook is designed for personal training follow-up, gym programming, and regular fitness progress monitoring.
